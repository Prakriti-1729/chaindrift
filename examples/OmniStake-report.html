eoa-check
OmniStake.sol:48 in OmniStake.onlyHumans() — tx.origin == msg.sender used as an EOA check

Code tries to tell people from contracts (tx.origin == msg.sender, extcodesize == 0, address.code.length == 0). EIP-7702 lets ordinary accounts carry delegated code, and some chains have native account abstraction, so these checks no longer mean what they used to.
